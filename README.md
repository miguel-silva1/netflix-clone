# Netflix Clone

Site simples de streaming em HTML, CSS e JavaScript com visual inspirado na Netflix.

## Como rodar

1. Abra o arquivo `index.html` no navegador.
2. Ou use um servidor local simples, como:

```bash
python -m http.server 8000
```

Depois acesse: `http://localhost:8000`

## Estrutura

- `index.html` - estrutura da página
- `style.css` - estilos visuais e responsividade
- `script.js` - dados e interação dos cards e modal

## Observação

Este projeto foi criado para fins educativos e com design voltado para interface de streaming.
